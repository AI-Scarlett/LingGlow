# 先看这里：灵妆是什么？

**灵妆｜AI 助手主题与换肤，是给 Codex 和 WorkBuddy 换界面皮肤的本地工具。**

给你的 AI，换上喜欢的样子。

它不是 GPT，不会启动另一个 AI，也不修改模型。双击 `灵妆.app` 只会打开一个本地工作台：**不会因此启动、退出或重启 Codex / WorkBuddy。**

## 最简单的用法

1. 保留完整的灵妆发行文件夹。
2. 双击 `灵妆.app`。
3. 在顶部选择 Codex 或 WorkBuddy。
4. 去“皮肤库”选一套皮肤。浏览和预览都不会碰目标应用。
5. 点击应用后，先看清确认框；只有你点击“确认切换并重启”，所选应用才会退出、重新打开并加载皮肤。
6. 想撤销时，回到首页点击“恢复原版”，再确认一次。

## 免费版和 VIP

免费版可直接使用 4 套基础皮肤：

- Dream Portal 测试
- 石墨专注
- 海风浅蓝
- 青玉静谧

VIP 计划包含：

- 极光玻璃、落日工坊、紫雾星云 3 套 VIP 皮肤
- 用本地图片、配色、玻璃和圆角制作自己的皮肤
- 分别给 Codex、WorkBuddy 安排周一到周日的皮肤
- 当天检测到使用时提醒，可选现在切换、1 小时后或今天跳过
- 可选开启随登录提醒服务；默认不安装，也绝不会自动重启应用

但请注意：**当前支付、激活服务器和正式发行公钥还没有接入。** VIP 的界面、门禁、授权格式、自定义和排程逻辑已经实现，但现在还不是可以正式购买的会员服务。

## 当前支持到什么程度？

- **WorkBuddy 5.2.6：已真机验证。** 已实际完成退出、重启、加载皮肤、清理注入和恢复官方原版。
- **Codex 26.707.91948：仅 `generic-safe`。** 当前只开放背景、色板和基础玻璃层，尚未完成这个版本的真实重启换肤验证，不算精确适配。

Codex 或 WorkBuddy 更新后，灵妆会重新验签和检测页面能力。版本不完全匹配时会自动降级；关键条件不满足时会直接阻止换肤。

## 怎样恢复原版？

- 工作台能打开：选择目标应用，点击“恢复原版”，确认重启。
- 工作台打不开：在终端执行 `node src/cli.mjs restore-stock codex` 或 `node src/cli.mjs restore-stock workbuddy`。
- 不方便用终端：双击 `恢复Codex原版.command` 或 `恢复WorkBuddy原版.command`。

恢复不会删除对话、项目、登录状态或应用设置。

## 它明确不会做什么？

- 不修改 Codex / WorkBuddy 的 `app.asar` 或安装包。
- 不开放远程调试端口，只使用本机进程继承的 Pipe。
- 不允许皮肤携带任意 CSS、JavaScript 或网络图片。
- 不读取对话、提示词、终端、Cookie、账号或项目文件。
- 不因打开工作台、看预览或收到排程提醒而自动重启应用。
- 不把尚未接入的支付和 VIP 服务伪装成已经上线。
