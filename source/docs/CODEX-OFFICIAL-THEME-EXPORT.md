# Codex 官方主题导出（本地、手动导入）

灵妆可以把**已保存的 Codex 并集自定义皮肤**转换为一条
`codex-theme-v1:` 官方主题字符串。它是一个纯本地文本导出功能，不是
Codex 控制通道。

## 使用方式

1. 在灵妆中选择 **Codex**，创建或打开一套自定义皮肤。
2. 先点 **仅保存**。未保存的编辑草稿不能导出，避免把临时预览误当成可复用主题。
3. 在编辑器的 **Codex 官方主题**卡片中点 **复制官方主题字符串**。
4. 打开 Codex，进入 **设置 → 外观 → Theme**，使用其自己的导入入口粘贴该字符串。

导出时，灵妆不会启动、连接、重启、注入或修改 Codex；也不会创建 Apply Intent。
本地 API 路由是受会话 Token 与 Origin 双重保护的
`GET /api/union-profiles/<profileId>/codex-official-theme`，并且只读取私有
`union-profiles/` 中已保存、目标为 `codex` 的记录。

## 会包含什么

官方字符串只含 Codex 的公开主题值：

- `codeThemeId`
- 深浅模式、强调色、表面色、文字色、对比度
- UI/代码字体
- 窗口不透明选项
- Diff 新增/删除和 Skill 语义色

背景图、玻璃效果、Banner、圆角、动效、侧栏宽度和任何候选界面字段都**不会**被写进
官方主题字符串。它们仍然保存在统一 Schema 中，但是否可以运行时应用，必须遵循各
Agent 的独立适配和安全门禁。

导入时如果当前 Codex 版本不认识所选的 `codeThemeId`，应在 Codex 自己的导入界面中
改用其可用的代码主题；灵妆不会为了导出而探测或修改目标应用。

这些字段在能力 Schema 中会明确标记为 `manual-official-import`；这表示“可安全导出、
需用户手动导入”，而不是“灵妆已经在 Codex 运行时界面中应用了它”。
